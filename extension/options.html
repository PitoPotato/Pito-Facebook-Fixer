KEEP IT SAFE

Back up and protect your archive.

Export an encrypted copy and choose who can read what you saved.

Export a backup

Creates an encrypted file you keep yourself. Removing the extension deletes the archive, but not this file. Nothing is uploaded.

If you forget this password, the file can’t be opened.

Import a backup

Adds messages from a backup file. Messages already in the archive stay as they are, and nothing is deleted to make room.

Protect from browser cleanup

Password lock

Encrypts saved text, files, names and replies on this device. IDs, times, file types and sizes stay readable, and each message takes about 0.5 KiB more. While locked, new messages are still saved, but edits and media added to earlier messages are skipped until you unlock. If you forget the password, the only way out is to clear the archive.
